# The Archive

A curated collection of utilities, experiments, and fragments that don't fit neatly into any project category.

## What Lives Here

The Archive is a running log of tools I've built and open-sourced — things too small to be products but too useful to throw away.

## Selected Items

**`vec3-math`** — A zero-dependency 3D vector library for environments where importing Three.js is overkill. Used in early prototypes of this very world.

**`mdx-pipeline`** — A minimal Next.js content pipeline using `gray-matter` and `next-mdx-remote`. Powers the reading panel you are looking at right now.

**`toon-shader-kit`** — A reusable `DataTexture` gradient + `MeshToonMaterial` setup for React Three Fiber. Handles the cel-shading in every district of this world.

## Philosophy

Good tools are invisible. If you have to think about a library's API while using it, it has failed. I try to build things that disappear.
