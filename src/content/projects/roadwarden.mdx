# Roadwarden

A text-and-illustration RPG set in a dark fantasy world, built around a single mechanic: conversation.

## The Brief

Roadwarden was a commercial game project exploring what happens when you strip a role-playing game down to its core — words and choices — and trust the player's imagination to fill in the rest. No real-time combat. No minimap. Just a world built in prose.

## Technical Approach

The game runs on a custom dialogue engine built in Python, compiled to a portable runtime. Every NPC has a persistent memory state — what they've been told, what they've witnessed, what they believe about you. This creates a sense of a living world without expensive simulation.

- **Engine**: Custom Python dialogue state machine
- **Art**: Monochrome ink illustration
- **Platform**: PC, Mac

## What I Learned

Constraint is generative. A tight technical scope forced every design decision to be intentional. The absence of flashy systems made the writing carry more weight than it would have in a full-production RPG.
